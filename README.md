# 中枢期货量化交易系统 (Pivot Trading System)

[![Python 3.10+](https://img.shields.io/badge/python-3.10+-blue.svg)](https://www.python.org/downloads/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Market: Chinese Futures](https://img.shields.io/badge/Market-INE%20%7C%20DCE%20%7C%20SHFE-red.svg)](http://www.shfe.com.cn/)

基于中国商品期货市场（上期能源、大商所、上期所）特性研发的工业级系统化量化交易与风控框架。融合了经典量化著作（Rob Carver《Systematic Trading》、Perry Kaufman《Trading Systems and Methods》）的系统化设计理念，针对国内大宗商品宏观基本面中枢与非对称产业成本结构进行了深度适配与回测实证。

---

## 一、 系统核心策略

### 1. 上海原油（SC）：600 价值中枢对锁与 100% 保证金突破释放策略
- **产业基本面逻辑**：沙特与 OPEC+ 财政平衡成本（$75~$80/桶）构筑了全球原油硬底部，而欧美通胀压制与衰退预期压制顶部（$95~$100/桶），使得 600 元/桶成为上海原油天然的高对称性震荡中枢。
- **机制设计**：
  - 在 600 关口同时开立 1 手多单 + 1 手空单（初始净暴露为 0，零方向风险锁定）。
  - **100% 保证金利润突破触发**：原油 10% 保证金对应 60 点空间。当价格向上运行至 660 元（多单盈利 100% 保证金）时，斩断亏损空单，将多单释放为单边顺势仓位（或顺势加仓 1 手）。此时多头浮盈完全覆盖空头已实现亏损，实现**“零成本安全垫”顺势入场**。
  - **Smart Exit 锁盈体系**：摒弃宽幅回吐的传统吊灯止损，采用**保本底线锁 + 阶梯浮盈锁（Ratchet Lock）+ 跌破前一日低点抛物线止盈**。
- **实测表现（2021-2026 年真实连续数据，20 万初始本金）**：
  - **单多顺势**：净赚 **+92,080 元（+46.0%）**，最大回撤 31.5%；
  - **顺势加仓（2手奔跑）**：净赚 **+207,040 元（+103.5%，本金翻倍至 40.7 万元）**。

### 2. 大连铁矿石（I）：680 产业边际成本底轴与非对称偏态策略
- **产业基本面逻辑**：力拓/BHP/FMG/Vale 四大矿山 C1 现金成本仅 $15~$25/吨（CIF 港口成本 250~320 元/吨），而在 800 元以上高炉钢厂普遍吨钢亏损并触发发改委行政限价，因此 800 是典型的“估值天花板/做空区”而非对称中枢。
- **实证对比（750 中枢 vs 680 底轴）**：
  - **750 震荡中枢**：处于夹心泥潭，破位砍仓后顺势腿迅速撞上边界衰竭，24 轮交易净亏 **-355.0 点（-35,500 元）**，胜率仅 29.2%；
  - **680 边际成本底轴**：对标全球 90 分位边际开采成本（国内高成本地下矿+印度非主流矿成本线 $85~$90/吨），击穿后引发剧烈挺价反弹，10 轮交易净赚 **+72.2 点（+7,220 元）**，胜率 50%，最大回撤仅 4.11%。

### 3. 多品种资产组合动量（Portfolio Trend）
- 覆盖螺纹钢（RB）、铜（CU）、黄金（AU）、白银（AG）、PTA（TA）、豆粕（M）、白糖（SR）、国债（T）等多板块主流品种。
- 基于滚动 ATR（20日真实波幅）进行等风险波动率头寸分配（Volatility Targeting），动态管理账户风险敞口。

## 二、 核心量化模块与风控（Smart Exit）

```text
                       [ 600 中枢对锁建仓 (1多 + 1空) ]
                                      │
                 ┌────────────────────┴────────────────────┐
                 ▼                                         ▼
      [ 向上涨破 660 (+60点) ]                   [ 向下跌破 540 (-60点) ]
                 │                                         │
        平掉空单 (承担-60点)                      平掉多单 (承担-60点)
        多单浮盈 +60点安全垫                      空单浮盈 +60点安全垫
                 │                                         │
                 ▼                                         ▼
   [ Smart Exit 动态三级跟踪止盈 ]           [ Smart Exit 动态三级跟踪止盈 ]
   ├─ 1. 保本锁: 绝不破 645 成本底           ├─ 1. 保本锁: 绝不破 555 成本顶
   ├─ 2. 阶梯锁: 冲高分级锁定65%~75%浮盈    ├─ 2. 阶梯锁: 探底分级锁定65%~75%浮盈
   └─ 3. 破前低: 跌破前一日最低价平仓离场    └─ 3. 破前高: 涨破前一日最高价平仓离场
```

## 三、 代码仓库目录结构

```
pivot-trading-system/
│
├── backtest/                        # 回测核心模块
│   ├── system_sc_200k.py            # 20万本金原油 600 对锁全流程模拟引擎
│   ├── portfolio_ma.py              # 多品种趋势组合动量引擎
│   ├── ma_crossover.py              # 基础均线基准系统
│   └── backtest_trades_detail.py    # 逐笔交易穿透分析工具
│
├── scripts/                         # 实盘与策略分析脚本
│   ├── backtest_sc_upward_100pct.py # 原油 600 向上盈利 100% 入场平空策略复盘
│   ├── compare_750_680.py           # 铁矿石 750 vs 680 敏感性回测实证
│   ├── print_cycles_table.py        # 原油对锁逐轮账本生成器
│   ├── hedge_and_atr_analysis.py    # 商品 ATR 与跨品种对冲统计
│   ├── fetch_data.py                # AkShare 主连数据接口
│   └── fetch_multi.py               # 多品种历史 K 线批量抓取
│
├── data/                            # 数据仓库
│   ├── raw/                         # 原始日线数据（SC0, I0, RB, CU, AU等）
│   └── processed/                   # 回测账本与周期流水记录
│
├── .gitignore                       # 严格的安全与脱敏过滤规则
└── README.md                        # 系统架构与使用说明
```

## 四、 快速开始

### 1. 环境准备
推荐使用 Python 3.10 或更高版本：
```bash
pip install akshare pandas numpy backtrader matplotlib plotly
```

### 2. 运行原油 600 向上盈利 100% 策略复盘
```bash
python scripts/backtest_sc_upward_100pct.py
```

### 3. 运行铁矿石 750 与 680 成本轴对比回测
```bash
python scripts/compare_750_680.py
```

### 4. 导出原油逐笔盈亏明细账本
```bash
python scripts/print_cycles_table.py
```
